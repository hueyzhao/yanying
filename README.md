# 言映 Yanying

### 说出你的想法，把素材变成故事。

想做一条视频，却不想从头学习剪辑？

言映让你在熟悉的 AI 工作台里，用聊天的方式制作短片。告诉 AI 你想表达什么，交给它准备好的图片、视频和音频，让它帮你组织故事、安排镜头、添加字幕，再由言映在电脑上完成制作。

**从旅行回忆到产品介绍，从绘本故事到知识分享，让你的想法有画面。**

## 你可以用言映做什么？

📷 **把照片做成回忆短片**

旅行照片、生活片段、一次难忘的活动，配上几句文字，串成值得保存的故事。

📖 **把插画做成故事视频**

为几幅画安排剧情和字幕，制作绘本片段、睡前故事或知识讲解。

🛍️ **把产品素材做成介绍视频**

整理产品图片与展示片段，让 AI 帮你梳理内容，把特点讲清楚。

🎙️ **给你的声音配上画面**

用准备好的旁白或音乐，搭配图片、视频和字幕，让表达更完整。

## 像聊天一样制作视频

你可以这样开始：

> “把这些图片做成一条 20 秒的小故事，风格温暖一点，加上中文字幕。”

先让 AI 帮你整理剧情，看看镜头如何安排，再交给言映制作。

想调整，也可以直接说：

> “开头再简洁一点，最后一幕多停留两秒，保持视频总长不变。”

不必自己逐项调整画面尺寸、镜头长度和字幕。言映负责完成这些重复工作，并把视频保存到你的电脑上。

每次制作都会生成新的成片，方便保留和比较不同版本。

## 在你熟悉的 AI 工作台里使用

言映可通过本地工具接入 **WorkBuddy、TraeWork、Codex、Claude 等 AI 工作台**，让你继续使用熟悉的对话界面。

无需为了制作一条短片，再学习一套复杂的剪辑软件。

> 请使用支持本地文件操作和工具调用的客户端或模式。各工作台的安装、授权和接入方式有所不同，并非所有网页聊天模式都能直接使用。

## 复制一段话，开始体验

**让 AI 帮你完成安装，把精力留给创作。**

在你的 AI 工作台中开启一个本地任务，把下面这段话复制进去：

```text
请帮我安装并试用言映：
https://github.com/hueyzhao/yanying

请先阅读项目的 README 和安装使用说明，
检查当前电脑和工作台是否支持，再帮我完成本地安装与工具连接。

请你完成可以自动处理的步骤，不要让我手动输入命令或编辑配置。
已有的安装和配置请复用，不要覆盖我的其他设置。
遇到必须由我完成的授权，请告诉我需要点击什么。
如果当前环境无法完成某一步，请如实说明，不要假装安装成功。

安装完成后，使用项目附带的原创示例，
制作一条 20 秒的无声中文字幕视频，
并展示实际生成的成片或可打开的文件链接。

不调用付费 API，不下载 AI 大模型，不购买任何服务。
```

首次安装需要联网准备必要的制作工具。过程中，AI 可能请你选择保存位置，或允许访问文件、运行本地工具。

**你只需按提示完成必要确认，无需自己编写代码。** 自动完成的程度取决于工作台具备的权限与能力。

[需要更详细的说明？查看安装指南](docs/workbuddy.md)

## 安装后，做一条属于你的视频

### 1. 准备素材

把你有权使用的照片、插画、视频，以及可选的旁白或音乐，放进一个文件夹，交给 AI 查看。

还没有素材，可以先使用项目附带的原创示例。

### 2. 说出你的想法

复制下面这段话，也可以换成你自己的主题：

```text
用言映，把我提供的素材做成一条 20 秒的视频。

请先查看实际素材，再帮我写一个完整的小故事，
安排四个镜头，每镜 5 秒，并加上中文字幕。

先把剧情和素材安排给我看，确认后再制作。
如果素材不够，请告诉我缺什么，不要假装已经生成。
没有音频就先做无声字幕版，不调用付费 API。
```

### 3. 查看成片，继续调整

制作完成后，AI 会提供视频文件的位置。打开视频看看效果，再告诉它你想改哪里：

```text
第二个镜头的字幕再简洁一点，
结尾更温暖一些，保持总时长 20 秒。
请另存一版，保留之前的视频。
```

**从第一版开始，边看边改，把故事慢慢做成你喜欢的样子。**

## 为什么选择言映？

### 把精力留给故事

你决定想表达什么，AI 协助整理内容，言映完成本地制作，减少重复操作。

### 制作前，先发现问题

自动检查分镜总时长、字幕字数、素材是否齐全，以及文字分镜是否遗漏角色描述，帮助你减少返工。

### 用已有素材就能开始

照片、插画、视频片段和录音都可以成为创作起点。不必先购买视频生成服务，也不需要下载大型 AI 模型。

### 成片留在自己的电脑上

输出常见的 MP4 视频，同时提供单独的字幕文件，方便播放、分享或继续编辑。

### 免费开源，按自己的节奏使用

言映的本地合成功能不收取 API 费用。你可以先做一条短片，再决定如何扩展自己的创作流程。

## 当前支持的能力

| 功能 | 你可以得到什么 |
|---|---|
| 图片制作视频 | 按分镜顺序与时长展示照片、插画 |
| 视频片段编排 | 按指定时长截取或循环已有视频 |
| 中文字幕 | 直接显示在画面中，并另存字幕文件 |
| 旁白或音乐 | 导入一条准备好的音频 |
| 自动检查 | 检查时长、文字描述、字幕字数与素材路径 |
| 视频导出 | MP4，1280 × 720，25 帧／秒 |
| 制作长度 | 每条 2—120 秒，最多 24 个镜头 |

## 使用前，你可能想知道

**需要付费吗？**

言映免费开源，本地合成不调用付费 API。你使用的 AI 工作台可能消耗自身的模型额度，具体以对应平台和账号套餐为准。

**需要高配置电脑吗？**

当前的素材合成不需要专用显卡或本地大模型。制作速度取决于电脑配置、素材大小和视频长度。已在 Intel Mac 上完成本地制作验证，其他系统的安装体验仍在完善。

**只说一句话，就能凭空生成所有画面吗？**

当前版本需要已有图片或视频素材，AI 可以协助构思和安排内容。言映暂不包含自动生图、连续人物动画或自动配音。

**视频可以有声音吗？**

可以导入一条准备好的旁白或音乐。没有提供音频时，输出无声字幕视频。当前版本会移除视频素材原声，以提供的音频作为成片声音。

**素材会上传到哪里？**

视频合成在本地电脑上完成。你在对话中交给 AI 工作台的文字、图片或文件，仍遵循该平台的数据处理规则；本地制作不代表宿主模型也在本地运行。

**安装遇到问题怎么办？**

把错误信息交给正在协助安装的 AI，让它根据项目说明检查。也可以在 [GitHub Issues](https://github.com/hueyzhao/yanying/issues) 反馈，附上操作系统、工作台名称和报错内容，请勿上传密码或密钥。
