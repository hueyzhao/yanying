# 言映 Yanying

### 说出想法，用对话做视频。

**打字说需求，也可以通过 AI 工作台的语音输入，说出你想做的视频。**

一个故事、一段知识、一个想介绍的产品，都可以成为起点。让 AI 帮你梳理内容、安排画面和字幕，再调用言映在电脑上制作成片。想调整时，继续告诉它你的想法。

不用先学会剪辑，先把想表达的事情说出来。

## 可以用言映做什么？

### 说出一个想法，开始做一条视频

> “我想做一条 20 秒的小故事：一只迷路的小猫，在雨夜找到了一家温暖的书店。”

不用一开始就写好剧本、想清每个镜头。先告诉 AI 你想讲什么，让它帮你把一个念头整理成完整剧情，再安排镜头、字幕和制作步骤。

### 没有素材，也能先开始创作

> “我还没有图片，帮我想想这四个镜头应该是什么画面，角色要保持一致。”

让 AI 帮你列出所需画面、整理角色设定和生成提示词，再引导你使用工作台可用的画面生成工具，创作属于自己的素材。准备好画面后，交给言映制作成片。

已有图片或视频，也可以直接交给 AI 编排使用。

*当前言映负责本地视频编排、字幕与合成；画面生成需借助工作台或另行接入的生成工具，其可用性和费用取决于对应服务。*

### 想改哪里，说出来就好

> “开头更有悬念一点。”
>
> “字幕再短一些，最后一幕多停留两秒。”
>
> “保留这一版，再做一个温暖的结尾。”

从剧情到镜头安排，从字幕到停留时间，用对话提出修改，让 AI 调整后再调用言映制作。每次生成新的成片，方便保留和比较不同版本。

**你负责表达想法，AI 协助创作，言映完成视频制作。**

## 在你熟悉的 AI 工作台里使用

言映可通过本地工具接入 **WorkBuddy、TraeWork、Codex、Claude 等 AI 工作台**，让你继续使用熟悉的对话界面。

无需为了制作一条短片，再学习一套复杂的剪辑软件。

> 请使用支持本地文件操作和工具调用的客户端或模式。各工作台的安装、授权和接入方式有所不同，并非所有网页聊天模式都能直接使用。

## 复制一段话，开始体验

**让 AI 帮你完成安装，把精力留给创作。**

在你的 AI 工作台中开启一个本地任务，把下面这段话复制进去：

```text
请帮我安装并试用言映：
https://github.com/hueyzhao/yanying

请先阅读项目的 README 和安装使用说明，
检查当前电脑和工作台是否支持，再帮我完成本地安装与工具连接。

请你完成可以自动处理的步骤，不要让我手动输入命令或编辑配置。
已有的安装和配置请复用，不要覆盖我的其他设置。
遇到必须由我完成的授权，请告诉我需要点击什么。
如果当前环境无法完成某一步，请如实说明，不要假装安装成功。

安装完成后，使用项目附带的原创示例，
制作一条 20 秒的无声中文字幕视频，
并展示实际生成的成片或可打开的文件链接。

不调用付费 API，不下载 AI 大模型，不购买任何服务。
```

首次安装需要联网准备必要的制作工具。过程中，AI 可能请你选择保存位置，或允许访问文件、运行本地工具。

**你只需按提示完成必要确认，无需自己编写代码。** 自动完成的程度取决于工作台具备的权限与能力。

[需要更详细的说明？查看安装指南](docs/workbuddy.md)

## 安装后，做一条属于你的视频

### 1. 先说你想做什么

复制下面这段话，也可以通过工作台的语音输入说出自己的主题：

```text
我想用言映做一条 20 秒的视频：
一只迷路的小猫，在雨夜找到了一家温暖的书店。

请先帮我梳理完整剧情，安排四个镜头，每镜 5 秒，
写好中文字幕，并列出每个镜头需要的画面。
先把方案给我看，确认后再继续。
```

### 2. 让 AI 带你准备画面

**还没有素材？** 说出你想看到的画面，让 AI 帮你整理角色设定、生成提示词，引导你生成自己的图片或视频。

可以接着发送：

```text
我还没有素材。请根据刚才确认的分镜，
统一角色外观和画面风格，帮我准备每个镜头的生成提示词。

先检查当前工作台有没有可用的画面生成工具。
有的话，请说明能做什么、是否收费，再按我确认的方案生成；
没有的话，请给我可以复制使用的提示词，指导我准备素材。
不要把提示词当作已经生成的图片或视频。

素材准备好后，请检查是否齐全，调用言映制作成片。
没有音频就先做无声字幕版。未经我确认，不使用收费生成服务。
```

**已有素材？** 直接提供你有权使用的图片、视频和可选音频，让 AI 根据实际素材调整分镜，再交给言映制作。

### 3. 查看成片，继续调整

制作完成后，AI 会提供视频文件的位置。打开视频看看效果，再告诉它你想改哪里：

```text
第二个镜头的字幕再简洁一点，
结尾更温暖一些，保持总时长 20 秒。
请另存一版，保留之前的视频。
```

**从第一版开始，边看边改，把故事慢慢做成你喜欢的样子。**

### 4. 给故事加上声音

```text
请为这个故事加上中文旁白，再配一点温柔的背景音乐。
优先用本机系统声音和言映的本地配乐，不调用收费服务。
旁白按镜头对齐，背景音乐不要盖住人声，保留原来的无声版本。
```

也可以指定“轻快”或“舒缓”的配乐，或提供自己喜欢且有权使用的音乐。没有可用中文系统声音时，AI 会告诉你需要补齐什么。

## 为什么选择言映？

### 把精力留给故事

你决定想表达什么，AI 协助整理内容，言映完成本地制作，减少重复操作。

### 制作前，先发现问题

自动检查分镜总时长、字幕字数、素材是否齐全，以及文字分镜是否遗漏角色描述，帮助你减少返工。

### 从想法开始，逐步完成

有素材就直接编排，没有素材就让 AI 帮你规划画面、准备生成提示词。先确认故事，再准备素材，最后制作成片，不必一开始就把所有东西准备好。

### 成片留在自己的电脑上

输出常见的 MP4 视频，同时提供单独的字幕文件，方便播放、分享或继续编辑。

### 免费开源，按自己的节奏使用

言映的本地合成功能不收取 API 费用。你可以先做一条短片，再决定如何扩展自己的创作流程。

## 当前支持的能力

| 功能 | 你可以得到什么 |
|---|---|
| 图片制作视频 | 按分镜顺序与时长展示照片、插画 |
| 视频片段编排 | 按指定时长截取或循环已有视频 |
| 中文字幕 | 直接显示在画面中，并另存字幕文件 |
| 自动配音 | 用已安装的中文系统声音朗读旁白，按镜头对齐 |
| 背景音乐 | 三种简单本地合成配乐，或导入自己的音乐 |
| 自动混音 | 旁白与配乐混合，音乐淡入淡出并在人声出现时压低 |
| 自动检查 | 检查时长、文字描述、字幕字数与素材路径 |
| 视频导出 | MP4，1280 × 720，25 帧／秒 |
| 制作长度 | 每条 2—120 秒，最多 24 个镜头 |

## 使用前，你可能想知道

**需要付费吗？**

言映免费开源，本地合成不调用付费 API。你使用的 AI 工作台可能消耗自身的模型额度，具体以对应平台和账号套餐为准。

**需要高配置电脑吗？**

当前的素材合成不需要专用显卡或本地大模型。制作速度取决于电脑配置、素材大小和视频长度。已在 Intel Mac 上完成本地制作验证，其他系统的安装体验仍在完善。

**说话和打字都能用吗？**

可以用文字提出需求；如果你使用的 AI 工作台支持语音输入，也可以直接说话。语音输入由工作台提供，言映负责接收工具指令并制作视频。

**没有素材，怎么做出视频？**

先让 AI 帮你梳理故事和画面需求，再借助工作台可用的生成工具，或把提示词复制到你选择的工具中生成素材。准备好后，由言映合成视频。当前言映本身不包含生图、生视频服务；支持免费系统配音与简单本地配乐，使用外部生成工具可能产生费用。

**视频可以有声音吗？**

可以直接说：“用中文给这个故事配音，再加一点温柔的背景音乐。”言映会使用电脑已安装的中文系统声音配音，按镜头安排时间，并混入简单的本地合成配乐；也可以使用你自己的录音和音乐。有旁白时，音乐自动压低。

无需调用收费 API，但系统声音的自然度有限。macOS 已实测；Windows 需已安装的中文系统声音，适配尚未真机验证；Linux 暂使用导入录音。没有中文声音时会明确提示，不会自动转用收费服务。不要求声音、也未提供音频时，仍输出无声版。视频素材原声不会自动保留。

**素材会上传到哪里？**

视频合成在本地电脑上完成。你在对话中交给 AI 工作台的文字、图片或文件，仍遵循该平台的数据处理规则；本地制作不代表宿主模型也在本地运行。

**安装遇到问题怎么办？**

把错误信息交给正在协助安装的 AI，让它根据项目说明检查。也可以在 [GitHub Issues](https://github.com/hueyzhao/yanying/issues) 反馈，附上操作系统、工作台名称和报错内容，请勿上传密码或密钥。
