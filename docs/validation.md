日期：2026-10-23。环境：本机 macOS Intel，Bun 1.3.14。没有调用付费 API，没有下载 AI 模型。

| 验证项 | 结果 |
|---|---|
| 安装依赖并锁定 bun.lock | 通过；FFmpeg 首次下载约 75 MB，安装总计约 377 秒，受网络影响 |
| install.command 使用已有 Bun 执行 | 通过；生成本机 MCP 配置，重复运行无依赖变更 |
| TypeScript 类型检查 | 通过 |
| Skill 格式检查 | 通过 |

| 字幕画面 | 已查看四镜拼图；中文可读，字幕与各镜剧情对应 |
| MCP 初始化、工具列表、状态、校验、渲染 | 独立 MCP SDK 客户端实际调用通过；渲染调用约 2.7 秒 |
| 分镜合计时长错误 | 拒绝 |
| 分镜缺失角色完整描述 | 拒绝 |
| 字幕总字数过短 | 拒绝 |

未验证：WorkBuddy 桌面客户端内实际调用、付费云端技能、本地 Windows/Apple Silicon/Linux 真机、首次安装 Bun 的全新操作系统环境。不能把独立 MCP 客户端通过写成这些环境已通过。

没有把本机绝对路径、配置、生成视频、字体、凭证、模型或 node_modules 提交到源码仓库。安装时在 local/mcp.json 生成使用者自己的路径。

# 0.2.0 配音与配乐验证

日期：2026-10-25。本机 macOS Intel，使用已安装的 Tingting 中文系统声音，无新模型、无生成 API。

- TypeScript 检查、Skill 格式检查通过。
- `bun scripts/checkAudio.ts`：11 项回归通过，覆盖互斥主音轨、非法音量、三种非静音配乐、导入音轨混音、旧版无声模式、短音乐循环、缺失声音和旁白过长拒绝。
- 通过 Computer Use 在本机新版 TRAE 本地 Agent 模式实际调用成功。此处使用技能＋本地命令，没有将其算作 MCP 验证。
- 60 秒、6 镜中文系统配音＋gentle 配乐实际生成；各段从 0/10/20/30/40/50 秒开始，原始旁白每段约 4.2—4.6 秒，无需加速。
- 混音报告显示人声出现时压低音乐，峰值约 0.696（满幅为 1），未发生数字削波。无声旧功能与配音字段的启用行为保持兼容。
- 系统声音属于基础离线配音，配乐属于简单本地合成；未声明达到真人表演或商业作曲质量。

Windows System.Speech 适配已提供但没有 Windows 真机验证；没有已安装中文声音时返回明确错误。Linux 暂不支持自动系统配音，可导入录音并使用配乐。旧视频素材原声仍被去除。
